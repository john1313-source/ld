# 브라운스톤휘경 42평형 — 발코니 확장 인테리어 재설계 (Blender)

- 대상: 브라운스톤휘경 (서울 동대문구 휘경동), 공급 42.49평 / 전용 34.66평(114.58㎡), 방 4 · 욕실 2, 59세대 타입
- 조건(사용자 확정):
  - 방 개수 유지, 부부 + 자녀 2명(아들 둘), 모던 미니멀
  - **확장 범위: 제로준디자인 안과 같게.** 남측 발코니 3곳과 주방 뒤 발코니는 확장하고, **서재 뒤 발코니와 북동쪽 다용도실은 확장하지 않는다.** 처음의 "전부 확장"에서 바뀐 결정이다.
  - 설계 방향: 이 재설계안을 유지하면서 제로준디자인 설계도의 제약 조건만 반영한다.
- 결과물: `build_model.py` (모델 생성 스크립트), `brownstone_hwigyeong_114_redesign.blend`, `renders/*.png`

> 이 문서의 치수는 대부분 **추정치**다. 실측값은 서재(북측 침실) 2950 × 3100 mm 하나뿐이다.
> 공사 발주·가구 주문 전에 반드시 실측으로 바꿔야 한다.

## 1. 파일 여는 법

| 방법 | 명령 |
|---|---|
| 완성 파일 열기 | 블렌더에서 `brownstone_hwigyeong_114_redesign.blend` 열기 (블렌더 4.5 LTS에서 저장. 4.2 이상 권장 — 하위 버전 호환은 **직접 확인 못 함**) |
| 스크립트로 다시 생성 | 블렌더 → Scripting 탭 → `build_model.py` 열기 → Run Script |
| 명령줄 렌더 | `blender -b -P build_model.py -- --render` (`--quick`: 테스트용 저해상도, `--only=00_평면도,02_거실`: 일부 카메라만) |
| bpy 모듈 | `pip install bpy==4.5.*` 후 `python build_model.py --render` |

- 카메라: `00_평면도`(직교 탑뷰), `01_조감도`, `02_거실`, `03_주방식당`, `04_현관복도`, `05_안방`, `06_서재`, `07_자녀방1`
- 평면도와 조감도는 천장을 숨기고 라벨과 콘크리트벽 표시를 보이게 한다. 실내 컷은 그 반대다. 스크립트의 `set_visibility()`가 자동으로 처리한다.
- 컬렉션 구성: `01_벽체` / `02_창호_문` / `03_바닥` / `04_천장_조명` / `05_가구`(방별 하위) / `06_라이트` / `07_카메라` / `08_라벨` / `09_콘크리트벽(업체도면)`
- 한글 라벨 폰트(WenQuanYi Zen Hei)는 .blend 안에 포함(pack)되어 있다.

## 3. 설계 요약

### 공간 배분 (방 4개 유지)
| 기존 | 재설계 |
|---|---|
| 좌하 침실 + 드레스룸 + 욕실 | **안방 스위트**: 침실 → 워크인 드레스룸 → 안방욕실 동선. 안방욕실은 **반신욕조 750**과 젠다이. 확장부는 창가 라운지 |
| 우하 침실 2개 | **자녀방 1·2**: 남향 확장부를 창가 책상으로 쓰고 천장까지 붙박이장. 자녀방1의 장은 거실 쪽 벽에 붙여 소음을 줄인다. **자녀방2 창가 동쪽 모서리에는 우수관 박스(0.3×0.3 m, 추정)가 있어서 책상을 그만큼 줄였다** |
| 상부 침실 (실측 2950×3100) | **서재·게스트룸**: 뒤 발코니를 확장하지 않아서 가구를 방 안에 배치했다. 서측 벽(안방욕실 벽)에 2인 책상과 상부 선반, 동측 벽에 소파베드, 발코니 창 옆에 좁은 책장. 발코니 창은 출입용이라 막지 않는다 |
| 서재 뒤 발코니 | **비확장.** 수납 선반을 두고, 실외기실로 들어가는 동선을 유지한다 |
| 거실 | 남측 확장으로 깊이가 약 5.1 m가 된다. 서측(안방 벽)은 포세린 슬랩 아트월과 플로팅 TV장, 동측(자녀방 벽)은 3.1 m 소파 |
| 주방 + 뒤 발코니 | 확장부 창가에 싱크, 인덕션 아일랜드(2.1 m)와 천장형 후드, 좌우 키큰장, 6인 식탁. **분전함은 좌측 키큰장 안에 두고 점검 도어를 표시**했다(업체 설계도 15쪽 위치 준용) |
| 북동쪽 다용도실 | **비확장.** 세탁기·건조기 직렬 배치와 다용도 싱크. 주방과는 발코니용 유리 여닫이문으로 연결 |
| 현관 | 천장까지 닿는 신발장(하부를 띄우고 간접등), 3연동 슬림 중문, 벤치와 전신거울 |
| 복도 끝 소실 | 팬트리(ㄷ자 선반) |

### 구조 (콘크리트벽)
평면도의 주황색 벽은 업체 설계도에서 "콘크리트벽"으로 표시된 벽이다. 대상은 안방-거실, 안방 북측, 드레스룸-복도, 서재 남측, 서재-주방(뒤 발코니 칸막이 포함), 주방-공용욕실, 공용욕실 남측, 주방-다용도실, 거실-자녀방1, 자녀방1-자녀방2, 자녀방 북측이다.
**이 재설계는 이 벽들을 하나도 철거하지 않는다.** 철거하는 벽은 남측 발코니와 주방 뒤 발코니의 창호벽뿐이다.
("콘크리트벽"이 곧 내력벽이라는 뜻은 아니다. 내력벽인지는 구조도면으로 확인해야 한다.)

### 마감 (모던 미니멀)
- 바닥: 거실·주방·복도는 **600×1200 포세린 타일(웜그레이)** 한 가지로 통일. 침실류는 **광폭 강마루(라이트 오크)**. 욕실은 차콜 300×600. 현관은 다크그레이 600×600. 비확장 공간은 시멘트 마감
- 벽과 천장: 무몰딩, 웜화이트 도장. 문은 문틀 없는 히든도어로 표현
- 조명: 거실과 복도는 천장 매입 라인조명, 방은 매입 다운라이트. 식탁과 협탁 위에 펜던트. TV장, 신발장, 거울에 간접등
- 가구 톤: 화이트, 그레이지, 오크의 3가지 톤과 세이지 그린 포인트

### 비확장 유지 공간
- 서재 뒤 발코니, 북동쪽 다용도실: 사용자 결정으로 확장하지 않음
- 도면에서 ⊠로 표시된 네 곳: **실외기실이나 대피공간으로 추정**해서 루버도어로 남겼다(**가정**). 업체 설계도에서도 확장하지 않았다(**직접 관찰**). 이 중 어디가 법정 대피공간인지는 확인하지 못했다.

## 4. 미해결 — 확인이 필요한 것

1. **내력벽 여부**: 콘크리트벽 위치는 업체 설계도로 확인했다. 그중 어느 것이 내력벽인지, 그리고 남측 창호벽 양 끝의 날개벽이 구조체인지는 구조도면으로 확인해야 한다.
2. **대피공간과 실외기실**: ⊠ 네 곳의 용도, 그리고 하향식 피난구가 있는지.
3. **보일러 분배기 위치**: 업체 설계도 17쪽에 "보일러분배기"가 주방에 표기되어 있다. 하지만 라벨이 식탁 의자 위에 겹쳐 있어서 정확한 위치를 판독하지 못했고, 모델에도 넣지 않았다.
4. **우수관 박스의 실제 크기와 위치**: 도면 판독 추정(0.3×0.3 m, 자녀방2 창가 동쪽 모서리)
5. **발코니 확장 행위허가**: 관리주체 동의와 구청 신고 절차, 단열·결로 기준(창호 등급, 단열재 두께)
6. **확장부 난간**: 창 하단 높이를 0.45 m로 가정했다. 창 하단이 낮으면 안전난간 기준을 확인해야 한다.
7. **천장고와 보(beam) 위치**: 2.30 m로 가정했다. 확장부에 보가 있으면 라인조명과 커튼박스 계획이 바뀐다.
8. **주방 동선 폭**: 아일랜드와 식탁 사이의 의자 뒤 여유가 약 0.35 m다. 실측 후 식탁 크기를 조정해야 할 수 있다.
9. **예산**: 받지 않았다. 필요하면 공정별 견적 항목표를 따로 만들겠다.
