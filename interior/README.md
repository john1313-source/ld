# 브라운스톤휘경 42평형 — 발코니 확장 인테리어 재설계 (Blender)

- 대상: 브라운스톤휘경 (서울 동대문구 휘경동), 공급 42.49평 / 전용 34.66평(114.58㎡), 방 4 · 욕실 2, 59세대 타입
- 조건(사용자 확정):
  - 방 개수 유지, 부부 + 자녀 2명(아들 둘), 모던 미니멀
  - **확장 범위: 제로준디자인 안과 같게.** 남측 발코니 3곳과 주방 뒤 발코니는 확장하고, **서재 뒤 발코니와 북동쪽 다용도실은 확장하지 않는다.** 처음의 "전부 확장"에서 바뀐 결정이다.
  - 설계 방향: 이 재설계안을 유지하면서 제로준디자인 설계도의 제약 조건만 반영한다.
  - 발코니 확장 행위허가: **완료**(사용자 확인). 대피공간: **없음**(사용자 확인)
  - 예산: **가구 포함 약 5억 원**(사용자 제시)
  - 모든 방에 **시스템에어컨**(사용자 요청)
- 결과물: `build_model.py` (모델 생성 스크립트), `brownstone_hwigyeong_114_redesign.blend`, `renders/*.png`

> 이 문서의 치수는 대부분 **추정치**다. 실측값은 서재(북측 침실) 2950 × 3100 mm 하나뿐이다.
> 공사 발주·가구 주문 전에 반드시 실측으로 바꿔야 한다.

## 1. 파일 여는 법

| 방법 | 명령 |
|---|---|
| 완성 파일 열기 | 블렌더에서 `brownstone_hwigyeong_114_redesign.blend` 열기 (**블렌더 5.2.2 LTS에서 저장**. 4.x에서 열리는지는 **직접 확인 못 함** — 안 열리면 `build_model.py`로 다시 생성) |
| 스크립트로 다시 생성 | 블렌더 → Scripting 탭 → `build_model.py` 열기 → Run Script |
| 명령줄 렌더 | `blender -b -P build_model.py -- --render` (`--quick`: 테스트용 저해상도, `--only=00_평면도,02_거실`: 일부 카메라만) |
| bpy 모듈 | `pip install bpy==4.5.*` 후 `python build_model.py --render` |
| 웹 뷰어 모델 | `blender -b -P export_web.py` → `web/brownstone_114.glb`. `web/brownstone_114.gltf.json`은 같은 GLB의 BIN 청크를 base64 data URI로 넣은 glTF JSON(뷰어가 읽는 파일) |

### 내 PC(RTX 4080 SUPER)에서 GPU로 보기·렌더하기
1. 블렌더에서 `.blend`를 연다. 3D 화면은 **Material Preview(GPU)**, 거실 카메라 시점으로 열리도록 저장되어 있다.
2. 처음 한 번만: 위쪽 **Scripting** 탭 → Open → `setup_gpu.py` → ▶ Run Script. 환경설정이 **OptiX + RTX 4080 SUPER**로 바뀌고 저장된다.
3. F12로 렌더한다. 8컷을 한 번에 렌더하려면 명령 프롬프트에서 `blender -b -P build_model.py -- --render --gpu` (블렌더 설치 폴더가 PATH에 없으면 blender.exe 전체 경로 사용). 파일의 렌더 장치는 GPU, 샘플 256, 노이즈 제거 OptiX로 설정되어 있다. 2번을 하지 않으면 블렌더가 CPU로 렌더한다.
- **Microsoft Store판 블렌더**는 `blender.exe`를 명령줄에서 직접 실행할 수 없다(접근 거부). 대신 `%LOCALAPPDATA%\Microsoft\WindowsApps\blender-launcher.exe -b -P build_model.py -- --render --gpu`를 쓴다. 이 런처는 실행이 끝날 때까지 기다리지만 콘솔 출력을 넘겨주지 않는다(직접 확인).
- 2번(`setup_gpu.py`)은 GUI용이다. 백그라운드에서는 같은 설정(`compute_device_type='OPTIX'`, OptiX 장치 `use=True`, `save_userpref`)을 스크립트로 실행하면 된다.
- 2026-09-24 이 PC 실행 결과(직접 확인): 8컷 모두 OptiX · RTX 4080 SUPER, 256샘플로 렌더. 컷당 3.6~9.4초, 모델 생성·저장 포함 전체 약 70초.
- 둘러볼 때는 뷰포트 우상단의 3번째 아이콘(Material Preview)을 쓴다. 4번째(Rendered)는 Cycles로 실시간 계산해서 더 무겁다.
- 카메라 바꾸기: 오른쪽 목록 `07_카메라`에서 카메라 선택 → Ctrl + 숫자패드 0. 천장을 숨기려면 `04_천장_조명` 옆 눈 아이콘을 끈다.

- 카메라: `00_평면도`(직교 탑뷰), `01_조감도`, `02_거실`, `03_주방식당`, `04_현관복도`, `05_안방`, `06_서재`, `07_자녀방1`
- 평면도와 조감도는 천장을 숨기고 라벨과 내력벽 표시를 보이게 한다. 실내 컷은 그 반대다. 스크립트의 `set_visibility()`가 자동으로 처리한다.
- 컬렉션 구성: `01_벽체` / `02_창호_문` / `03_바닥` / `04_천장_조명` / `05_가구`(방별 하위) / `06_라이트` / `07_카메라` / `08_라벨` / `09_내력벽`
- 한글 라벨 폰트는 블렌더에 함께 설치되는 **Noto Sans CJK Regular(OFL 라이선스)**이며 .blend 안에 포함(pack)되어 있다. 공개 저장소라서 맑은 고딕 같은 OS 번들 폰트는 넣지 않는다(사용자 결정). 폰트마다 글자 크기 기준이 달라서 '가' 높이로 라벨 크기를 맞춘다(`label_scale`).

## 3. 설계 요약

### 공간 배분 (방 4개 유지)
| 기존 | 재설계 |
|---|---|
| 좌하 침실 + 드레스룸 + 욕실 | **안방 스위트**: 침실 → 워크인 드레스룸 → 안방욕실 동선. 안방욕실은 **반신욕조 750**과 젠다이. 확장부는 창가 라운지 |
| 우하 침실 2개 | **자녀방 1·2**: 남향 확장부를 창가 책상으로 쓰고 천장까지 붙박이장. 자녀방1의 장은 거실 쪽 벽에 붙여 소음을 줄인다. **자녀방2 창가 동쪽에는 우수관 박스(0.60×0.37 m)와 그 앞 낮은 장이 있어서 책상을 그만큼 줄였다** |
| 상부 침실 (실측 2950×3100) | **서재·게스트룸**: 뒤 발코니를 확장하지 않아서 가구를 방 안에 배치했다. 서측 벽(안방욕실 벽)에 2인 책상과 상부 선반, 동측 벽에 소파베드, 발코니 창 옆에 좁은 책장. 발코니 창은 출입용이라 막지 않는다 |
| 서재 뒤 발코니 | **비확장.** 수납 선반을 두고, 실외기실로 들어가는 동선을 유지한다 |
| 거실 | 남측 확장으로 깊이가 약 5.1 m가 된다. 서측(안방 벽)은 포세린 슬랩 아트월과 플로팅 TV장, 동측(자녀방 벽)은 3.1 m 소파 |
| 주방 + 뒤 발코니 | 확장부 창가에 싱크, 인덕션 아일랜드(2.1 m)와 천장형 후드, 좌우 키큰장. 식탁(2.0×0.9 m)은 주방 남쪽 끝(복도 접경)에 두어 **아일랜드와 의자 뒤 여유 약 1.15 m, 식탁 남쪽 복도 통로 약 1.2 m**를 확보했다. **분전함은 좌측 키큰장 안에 두고 점검 도어를 표시**했다(업체 설계도 15쪽 위치 준용) |
| 북동쪽 다용도실 | **비확장.** 세탁기·건조기 직렬 배치, 다용도 싱크, **보일러와 분배기(북동쪽 모서리)**. 주방과는 발코니용 유리 여닫이문으로 연결 |
| 현관 | 천장까지 닿는 신발장(하부를 띄우고 간접등), 3연동 슬림 중문, 벤치와 전신거울 |
| 복도 끝 소실 | 팬트리(ㄷ자 선반) |

### 구조 (내력벽)
평면도의 주황색 벽은 업체 설계도에서 주황색으로 표시된 벽이며, **모두 내력벽이다(사용자 확인)**. 대상은 안방-거실, 안방 북측, 드레스룸-복도, 서재 남측, 서재-주방(뒤 발코니 칸막이 포함), 주방-공용욕실, 공용욕실 남측, 주방-다용도실, 거실-자녀방1, 자녀방1-자녀방2, 자녀방 북측이다.
**이 재설계는 이 내력벽을 하나도 철거하거나 뚫지 않는다.** 철거하는 벽은 남측 발코니와 주방 뒤 발코니의 창호벽뿐이다.
확장하는 발코니의 창호벽은 양 끝 날개벽까지 **전부 철거한다(사용자 확인)**. 모델도 날개벽 없이 그렸다.

### 마감 (모던 미니멀)
- 바닥: 거실·주방·복도는 **600×1200 포세린 타일(웜그레이)** 한 가지로 통일. 침실류는 **광폭 강마루(라이트 오크)**. 욕실은 차콜 300×600. 현관은 다크그레이 600×600. 비확장 공간은 시멘트 마감
- 벽과 천장: 무몰딩, 웜화이트 도장. 문은 문틀 없는 히든도어로 표현
- 공조: 거실·주방·안방은 4way 시스템에어컨(0.95 m 패널), 서재·자녀방은 소형 4way(0.62 m). 위치는 조명과 가구를 피한 디자인 값
- 조명: 거실과 복도는 천장 매입 라인조명, 방은 매입 다운라이트. 식탁과 협탁 위에 펜던트. TV장, 신발장, 거울에 간접등
- 가구 톤: 화이트, 그레이지, 오크의 3가지 톤과 세이지 그린 포인트

### 비확장 유지 공간
- 서재 뒤 발코니, 북동쪽 다용도실: 사용자 결정으로 확장하지 않음
- 도면에서 ⊠로 표시된 네 곳: **대피공간은 없다(사용자 확인)**. 실외기실로 보고 확장하지 않았다. 업체 설계도에서도 확장하지 않았다(**직접 관찰**).

## 4. 미해결 — 확인이 필요한 것

1. **확장부 창 하단 높이와 난간**: 0.45 m로 가정했다. 행위허가가 끝났으니 난간 기준은 시공사가 맞췄을 것으로 보고, 설계에는 영향이 작다(창가 책상·라운지 가구 높이 정도).
2. **예산**: 품목별 대조는 [`BUDGET.xlsx`](BUDGET.xlsx)(엑셀, 수식 연결)와 [`BUDGET.md`](BUDGET.md)에 있다. 레이지보이 소파는 사용자 지정 1,000만 원. 확인된 항목 합계는 약 1.08억~2.19억 원이다(소파 외 금액은 검색 요약 기준, 전해 들음). 남는 예산을 어디에 쓸지는 아직 정하지 않았다.
